# Computer Society of Kenya website

This is now a static website built with plain HTML, CSS and JavaScript. It has no Julia, server runtime, package installation, or build step.

## Open it

Open `index.html` in a browser. The navigation uses URL hashes (for example `#/membership`), so every section works even when the file is opened directly from disk.

## Files

- `index.html` — the standalone page shell
- `public/css/style.css` — all site styling and responsive rules
- `public/js/main.js` — navigation, page rendering, and site content
- `data/` — retained source JSON reference files

To deploy, upload the contents of this folder to any static hosting provider.
